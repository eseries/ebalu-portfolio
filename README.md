# Developer Portfolio

Milestone 1 of a frontend-only personal portfolio built with Next.js App Router, TypeScript, Tailwind CSS, and Lucide icons.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Checks

```bash
npm run lint
npm run typecheck
npm run build
```

## Configuration

Update `lib/portfolio.ts` with verified email, GitHub, LinkedIn, and Solar Energy project URLs. Until then, the UI intentionally uses clearly marked placeholders and `#` links. No contact form or backend is included in this milestone.
